## Behaviour

- `GET /services/searching/api/semantic?query=…&index=…&mode=hybrid|semantic&limit=…` returns `{ success, mode, data }`. Other providers answer 400 with a message.
- The `aiservice` backend calls `embed(texts, { model, dimensions })` on the AI service and reads `vectors`.
- A failed embedding leaves the documents searchable by keyword. `lastEmbedError` records why.

- A batch with failures emits `search:embed:error` (`{ searchContainer, documents, failed, error }`); `search:embed:complete` carries a `failed` count.
- `POST /services/searching/api/evaluate` takes `{ cases: [{ query, expectedId }], index, mode, k }` (1–500 cases, k 1–100) and returns `recallAtK`, `meanReciprocalRank` and a rank per case. Providers other than vector answer 400.
- The vector provider defaults to `semantic` mode. Keyword hits are always available with `mode: 'keyword'`; semantic hits appear once the background queue has embedded the documents (`flushEmbeddings()` waits for it).
